🗂️ Portfolio Repo Picker

Pick which GitHub repositories show up on your portfolio — no manual JSON editing.


  
  
  


  


  
  
  
  
  

  
Your token is only held in this page's memory for this session — it is never saved, stored, or sent anywhere except directly to GitHub's API.






  
Option A: Manual (no token needed)

  
    
    
  1. Enter your GitHub username and click Load My Repositories
    2. 
    
  2. Check the boxes next to the repos you want on your portfolio
    3. 
    
  3. Click Generate Config, then download the file
    4. 
    
  4. Replace repos-config.json in your repo with the downloaded file, then commit & push manually
    5. 
  


  
Option B: Auto-commit (one click, needs a token)

  
    
    
  1. Create a token: go to github.com/settings/tokens → Generate new token (fine-grained)
    2. 
    
  2. Under Repository access, select Only select repositories → choose your portfolio repo (e.g. kiranmunugoti.github.io)
    3. 
    
  3. Under Permissions, expand Repository permissions → set Contents to Read and write
    4. 
    
  4. Generate the token and copy it (it's shown only once)
    5. 
    
  5. Paste it into the GitHub Personal Access Token field above, confirm the repo name, and click Commit & Push Automatically
    6. 
    
  6. Done — no download/upload needed. GitHub Pages will rebuild your site within a minute or two
    7. 
  

  

    Because the token is scoped to only this one repo with only Contents write access, even if it leaked it couldn't touch your other repos or account settings. Still, treat it like a password — close this tab when you're done, and revoke the token from GitHub's settings page anytime you want.
