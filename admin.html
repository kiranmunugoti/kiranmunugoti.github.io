🗂️ Portfolio Repo Picker

Pick which GitHub repositories show up on your portfolio — no manual JSON editing.

Your token stays in this page's memory only — never saved, stored, or sent anywhere except directly to GitHub's API.


  
  
  
  

  






  
One-time setup: get a token

  
    
    
  1. Go to github.com/settings/tokens → Generate new token (fine-grained)
    2. 
    
  2. Under Repository access, select Only select repositories → choose your portfolio repo (e.g. kiranmunugoti.github.io)
    3. 
    
  3. Under Permissions, expand Repository permissions → set Contents to Read and write
    4. 
    
  4. Generate the token and copy it (it's shown only once)
    5. 
  


  
Then, every time you want to update your portfolio

  
    
    
  1. Paste the token into the GitHub Personal Access Token field at the top of this page
    2. 
    
  2. Click Load My Repositories
    3. 
    
  3. Check or uncheck any repo — it auto-saves to your live portfolio instantly, about a second after you stop clicking/typing
    4. 
    
  4. No buttons to click, nothing to download or upload — watch the "Auto-saving..." status turn into "✅ Auto-saved"
    5. 
  

  

    Prefer not to paste a token? Leave that field empty and use Generate Config → Download to update the file manually instead — both paths still work.
  

  

    Because the token is scoped to only this one repo with only Contents write access, even if it leaked it couldn't touch your other repos or account settings. Still, treat it like a password — close this tab when you're done, and revoke it from GitHub's settings page anytime you want a fresh one.
